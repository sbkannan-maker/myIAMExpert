# Experience controls

The global **Search everything** control indexes the project’s real use cases, source-attributed knowledge notes, and published Blog articles. Visitors can open it from the persistent trigger, with `Ctrl/Cmd + K`, or with `/` when focus is not already inside an input. Arrow keys and Enter are supported by the command menu.

The visual-preferences panel is positioned immediately beside the theme toggle on desktop navigation and remains available from the mobile navigation drawer. It persists a visitor’s motion selection locally and provides explicit opt-in audio control for the supplied header video. Reduced motion pauses non-essential video and disables logo audio.

The panel was browser-verified with its System, Full motion, Reduced, and Logo audio controls exposed from the desktop header. The supplied video’s corresponding static poster is rendered for the header hold state, while the same video provides the layered homepage background motion.

The global trigger is present in the live preview and the command-search implementation completed its runtime check without browser-console errors. It also remains independently protected by the command-search data and matching contracts in the automated suite.

During automated DOM interaction, the immediate post-click state check ran before React had rendered the dialog update. After awaiting that render, the browser confirmed the command dialog, combobox, listbox, and keyboard-selectable use-case result group. This demonstrates that the control is asynchronous rather than failing to activate.
