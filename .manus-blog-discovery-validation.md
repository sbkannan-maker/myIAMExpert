# Blog Discovery Validation

The Blog search field was tested with `OAuth 2.0`. It reduced the result list from two notes to the single Entra ID × SailPoint IIQ integration article, confirming keyword filtering works against article content and tags.

The Integration & Delivery category control selected the matching category and retained the single integration note. Clearing the keyword query preserved the selected category, confirming the keyword and category filters compose predictably.

The alternate Architecture & Governance category control was then selected and displayed its single matching governance article. The same controls are present in the mobile layout and preserve the selected filter state.
